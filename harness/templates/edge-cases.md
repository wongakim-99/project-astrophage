# 엣지케이스 체크리스트

새 API를 만들 때 이 목록을 훑고 해당하는 항목을 테스트에 포함한다.

---

## 인증 / 세션

- [ ] Authorization 헤더 없음 → 401
- [ ] 만료된 JWT → 401
- [ ] 형식이 잘못된 토큰 → 401
- [ ] 다른 유저의 리소스 접근 → 403

---

## 공개/비공개 이중 플래그

- [ ] `is_universe_public=true`, `is_public=false` → 403
- [ ] `is_universe_public=false`, `is_public=true` → 403
- [ ] 둘 다 false → 403
- [ ] 둘 다 true → 200 (정상 공개)
- [ ] 비공개 리소스를 슬러그로 직접 접근 → 403 (404 아님)

---

## 슬러그

- [ ] 같은 유저 내 슬러그 중복 생성 → 409
- [ ] 다른 유저와 동일 슬러그 → 200 (유저 내 유일, 전역 중복 허용)
- [ ] 슬러그에 특수문자/공백 → 422

---

## 항성 좌표 (pos_x, pos_y)

- [ ] 생성 후 좌표 확인 — None이면 배치 로직 버그
- [ ] 수정 시 좌표 변경 시도 → 무시되는지 확인 (좌표는 고정)
- [ ] 기존 항성 0개 은하 → 원점 (0, 0) + jitter
- [ ] 기존 항성 1개 → (+12, 0) + jitter
- [ ] 기존 항성 2개 이상 → 유사도 상위 k=3 가중 중심 + jitter

---

## 에너지 계산

- [ ] 30초 미만 체류 → `is_valid=false`, 에너지 미반영
- [ ] 30초 이상 체류 → `is_valid=true`, `energy_value=1.0`
- [ ] 편집(저장) 이벤트 → `is_valid=true`, `energy_value=2.0` (체류 시간 무관)
- [ ] Nova 전파: 유효 이벤트 발생 시 동일 은하 상위 k=5 항성에 `energy_value×0.25` 전파
- [ ] Nova 전파는 1-hop만 (전파의 전파 없음)
- [ ] 집계 범위: 최근 30일

---

## 입력 검증

- [ ] 필수 필드 누락 → 422
- [ ] 타입 불일치 (string 자리에 int 등) → 422
- [ ] 빈 문자열 필드 (title, content 등) → 422
- [ ] 극단적으로 긴 문자열 → 422 또는 DB truncation 없는지 확인

---

## DB / 동시성

- [ ] 동시 요청으로 슬러그 중복 레이스 컨디션 → 409 (DB 유니크 제약으로 보장)
- [ ] 트랜잭션 롤백 시 부분 반영 없는지 확인
